PAKET KOMPONEN GAMBAR
=====================

Setiap PNG pada folder bernomor adalah potongan individual dari gambar sumber.
Folder 00_sumber_asli berisi file asli untuk referensi.
manifest.json memuat nama file, sumber, koordinat crop, dan ukuran.

Catatan: potongan mempertahankan latar kartu/panel aslinya; ini adalah crop sprite,
bukan ekstraksi objek dengan latar transparan. Jika diperlukan, tahap berikutnya
bisa berupa pemisahan karakter/objek dari latar dan pembuatan atlas sprite.
