# Syariah-Quest — Visual Novel Design Pack (Asset Replacement)

Paket ini diperbarui memakai **Syariah-Quest-Assets-Individual.zip** sebagai sumber aset yang benar; ZIP sebelumnya tidak dipakai lagi.

Game diarahkan sebagai visual novel edukasi: scene ilustrasi, sprite mahasiswa/NPC, kotak dialog, pilihan respons, peta kota, misi, profil, dan koleksi badge.

## Menjalankan demo
1. Ekstrak `Syariah-Quest-Visual-Novel-Lengkap.zip`.
2. Buka `prototype/index.html` melalui Chrome/Edge.
3. Pilih Cerita untuk dialog interaktif; gunakan navigasi kiri untuk Peta Kota, Misi & Modul, Profil, dan Koleksi.

## Isi
- `Syariah-Quest-Assets-Individual.zip`: sumber aset pengganti yang dikirim terakhir.
- `assets/Syariah-Quest-Assets-Individual/`: seluruh isi ZIP sumber yang diekstrak.
- `prototype/`: UI visual novel dan crop scene/karakter dari lembar referensi baru.
- `referensi-screenshot/`: screenshot UI yang dikirim sebelumnya.
- `DESIGN-DIRECTION.md`, `KOMPONEN-VISUAL-NOVEL.md`: panduan desain dan komponen.

Catatan: crop karakter/background adalah potongan awal dari lembar referensi dan perlu diperiksa manual sebelum produksi. Pilihan, XP, dan progres masih simulasi, belum terhubung ke database.
